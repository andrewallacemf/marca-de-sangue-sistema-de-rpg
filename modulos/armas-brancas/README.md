# 🧩 Módulo: Armas brancas

Catálogo das **armas brancas** — o arsenal corpo a corpo convencional: lâminas, armas de
impacto, hastes, machados e foices. Faz parte da **coleção `armas`** (ver
[colecoes.md](../colecoes.md)).

> **Usa o sistema do núcleo.** Dano (matriz tamanho × tipo), propriedades (`CORT./PERF./CONT./
> VERS.` etc.), alcance ideal e durabilidade estão definidos em
> [sistema-base — equipamentos](../../sistema-base/listas/equipamentos-base.md). Este módulo só
