# Dō — os caminhos do Mukashi

Os **dō** são os arquétipos do Mukashi. Cada um **dá nome e flavor** a um
[arquétipo genérico](../../sistema-base/arquetipos/01-arquetipos-genericos.md) do núcleo (ou é
próprio do mundo) e, opcionalmente, ajusta o atributo secundário para **[KI](mecanicas-unicas/ki.md)**
quando há mística. Seguem a [estrutura de arquétipo](../../sistema-base/arquetipos/00-como-funcionam.md)
(primário/secundário, sugestões, e **habilidades de caminho** com pré-requisito de ≥ 2 habilidades
do caminho).

> 🧭 **Esqueleto para o Daniel completar.** Abaixo estão os dō mapeados para os genéricos, como
> ponto de partida. Falta a curadoria fina de cada um (sugestões definitivas, habilidades de
> caminho próprias e descrição de mundo).

## Dō mapeados aos genéricos

| Dō (Mukashi) | Base (genérico) | Flavor / ajuste |
|---|---|---|
| **Bushidō** — Caminho do Guerreiro | Guerreiro | Samurai; katana (versátil), armadura média (ō-yoroi). |
| **Sōhei** — Caminho do Bastão/Naginata | Baluarte / Guerreiro | Monge-guerreiro; naginata, bastão; segura a linha. |
| **Shinobi-dō** — Caminho da Sombra | Assassino | Shinobi; kunai/shuriken; usa [furtividade](../../modulos/furtividade/README.md). |
| **Kyūdō** — Caminho do Arco | Atirador | Arqueiro yumi; foco e precisão. |
| **Iaijutsu** — Caminho do Corte Rápido | Duelista | Saque-e-corte; katana leve/acuidade; bater e recuar. |
| **Onmyōdō** — Caminho do KI (místico) | Estrategista **ou** Curandeiro, secundário **KI** | Onmyōji/miko; [magia](mecanicas-unicas/magia.md), selos, bênçãos dos Kami. |
| **Caminho da Corte** | Líder | Diplomata/cortesão; honra e intriga; usa [conflito social](../../modulos/conflito-social/README.md). |

## Modelo para completar cada dō

```
## <Nome do dō>
Base: <arquétipo genérico> · Primário: <atributo> · Secundário: <atributo (ou KI)>
Descrição: <o que é este caminho no mundo>
Sugestões — Maestrias: … · Técnicas: … · Aspectos: … · Habilidades: …
Habilidades de caminho (≥ 2 do caminho): <se houver>
```
