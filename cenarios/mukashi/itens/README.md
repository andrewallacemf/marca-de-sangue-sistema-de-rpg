# Itens — Mukashi

As **armas** de Yamato não vivem aqui: cada uma aponta para a família da coleção `armas` onde está catalogada — ver [arsenal.md](../arsenal.md). Esta pasta guarda **itens genuinamente únicos** do cenário (sem equivalente no catálogo base): objetos rituais, amuletos, tesouros ligados aos Kami e relíquias de campanha.

> ⚠️ A DEFINIR (Daniel): o material original não trazia itens únicos fechados. Criar cada um a partir do [molde de item](../../_template-cenario/itens/_template-item.md) conforme a campanha pedir (ex.: um selo abençoado, uma lâmina lendária com propriedade própria).
