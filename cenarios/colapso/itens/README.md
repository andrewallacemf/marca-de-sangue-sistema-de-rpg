# Itens — Colapso

As **armas** apontam para o [arsenal](../arsenal.md). Os **equipamentos de veículo** (âncora,
gancho, escudos, espinhos etc.) e os itens de apoio ao reparo (Caixa de ferramentas, Caixa de
sabotagem) estão na
[lista de equipamentos do módulo `veiculos`](../../../modulos/veiculos/listas/lista-de-equipamentos.md).

## Sucata (recurso do cenário)

A **sucata** é a matéria-prima do ermo, usada para fabricar e reparar — e é a forma que o Colapso
dá às *peças de reposição* do módulo de veículos. Três tipos: **comum**, **eletrônica** e
**radioativa**.

A mecânica completa (coleta, conversão, e quanto cada reparo custa) está em
**[mecanicas-unicas/sucata.md](../mecanicas-unicas/sucata.md)**.

> ⚠️ A DEFINIR (Gabriel): artefatos pré-Colapso e relíquias de campanha (ex.: dispositivos que
> neutralizam radiação) a partir do [molde de item](../../_template-cenario/itens/_template-item.md).
