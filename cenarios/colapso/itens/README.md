# Itens — Colapso

As **armas** apontam para o [arsenal](../arsenal.md). Os **equipamentos de veículo** (âncora,
gancho, escudos, espinhos etc.) têm catálogo próprio em
[mecanicas-unicas/equipamentos de veículo](../mecanicas-unicas/equipamentos-de-veiculo.md).

## Sucata (recurso do cenário)

A **sucata** é a matéria-prima do ermo, usada para fabricar e reparar. Três tipos, do mais comum
ao mais raro:

- **Sucata comum** (genérica)
- **Sucata eletrônica**
- **Sucata radioativa**

Coleta-se com a ação **Procurar sucata** (ver [veículos](../mecanicas-unicas/veiculos.md)); alguns
traços convertem um tipo em outro (ver [traços do cenário](../mecanicas-unicas/tracos-do-cenario.md),
"Serralheiro e soldador").
